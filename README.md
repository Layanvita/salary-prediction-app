# Salary Prediction Web Application

## Project Overview

This project is a complete Data Science application that predicts salary based on a student's Grade 10 percentage.

The project covers the entire machine learning workflow:

* Data Collection
* Data Preprocessing
* Model Training
* Model Evaluation
* Model Deployment using Flask

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Flask
* Jupyter Notebook

## Project Workflow

1. Load dataset
2. Clean and preprocess data
3. Train Linear Regression model
4. Save model using Pickle
5. Build Flask web application
6. Generate salary predictions through a web interface

## Features

* User-friendly web interface
* Real-time salary prediction
* Machine learning model integration
* End-to-end deployment-ready application

## How to Run

1. Open cmd and navigate to project folder path

2. Start the Flask application:

python app.py

3. Open:

http://127.0.0.1:5000

## Output

The application predicts salary based on the Grade 10 percentage entered by the user.
